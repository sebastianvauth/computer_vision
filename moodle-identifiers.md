# Moodle Identifier Reference

Paste these identifiers into the LTI activity setting that is passed to the provider as the progress `identifier` or `goal/prefix` value.

Recommended use:

- Use a chapter identifier when one Moodle activity should grade a whole chapter.
- Use a lesson identifier when one Moodle activity should grade one lesson.
- Avoid page identifiers with `0` sections, such as many podcast-only pages, because they cannot produce meaningful progress percentages.
